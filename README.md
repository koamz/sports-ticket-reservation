# Sports Ticket Reservation System

A database project designed for managing sports events, ticket reservations, payments, and reporting processes.

## 📌 Project Overview

This system provides a relational database structure for handling:

- User management
- Sports and teams
- Match scheduling
- Venue management
- Ticket reservations
- Payment processing
- Reporting system

The project was developed as part of a Database Systems course.
